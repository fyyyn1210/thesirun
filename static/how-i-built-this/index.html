How I built this

A thesis-as-a-run recap for five nations, built by chatting with an AI coding agent.

The stack

  • FastAPI + SQLite (Python stdlib sqlite3), one file, one process
  • Plain HTML + vanilla JS + Tailwind CSS v4, built locally, no CDN
  • Flat runner illustrations from one pose kit, drawn as SVG on pages and with Canvas on share cards
  • No accounts, no tracking. Only anonymous numbers reach the server.

Architecture

Your phoneForm, story, and share card run here. Name, song, and phrase never leave it.
HTTPS · numbers only

One process

FastAPI app
  • GET / Static pages, fonts, and CSS
  • POST /api/run Validate, insert, return real percentiles
  • GET /api/stats Five nations and campus aggregates, 30 s cache
  • CRON 00:00 UTC Daily report: yesterday's champions
SQL · bound parameters
SQLite on a persistent diskNumbers, country, degree, optional campus. No IPs.

Prompts I actually used

  1. "kita akan pakai fast api + html + tailwind … tapi tailwindnya jangan yang cdn"

    We'll use FastAPI + HTML + Tailwind, but no Tailwind CDN.

  2. "coba buatkan desain … biru, kita coba coba style baru, deep reset"

    Try a new blue style from scratch, researched against similar games.

  3. "antar personal, antar kampus, dan antar negara (indo, india, china, us, jepang)"

    Add duels between friends, campuses, and five nations.

  4. "hajar2 aja, refaktor apapun gaskan"

    Go all in, refactor anything.

Platform features used

  • Server app
  • Persistent SQLite
  • Daily cron
  • Env vars
  • One-click rollback

Privacy by design

Your nickname, song, and go-to phrase never leave your device. Friends' duel history stays on your phone. The server stores only numbers, country, degree, and an optional campus. IP addresses are never stored. Percentiles appear only once a group has 30 real runners. No fake data, ever.
